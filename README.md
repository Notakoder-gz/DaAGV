# AMR / AGV 2D Map & Traffic Editor

Портативная десктопная утилита для визуализации, редактирования и выравнивания 2D растровых SLAM-карт (occupancy grid) и графов движения / бизнес-карт трафика (точки/сайты, направленные сегменты, зоны с ограничениями) для робототехнических систем (AMR / AGV / FMR).

---

## 🚀 Основные возможности

1. **Поддержка форматов данных `.xrobot` и ROS**:
   - Чтение и экспорт структуры `.xrobot` (`map.json`, `project_info.json`, `new_map.png`, `traffic_map/*.json`).
   - Совместимость с картами ROS (`.yaml` + `.png` / `.pgm`).
2. **Многослойный холст (Canvas Renderer)**:
   - Слой 1: Базовая растровая карта SLAM (сетка занятости).
   - Слой 2: Граф движения трафика (векторные узлы, дуги, полигональные зоны).
   - Поддержка бесконечного панорамирования (Pan) и плавного масштабирования (Zoom).
   - Управление видимостью и прозрачностью каждого слоя.
3. **Инструмент выравнивания карт (Map Alignment)**:
   - Визуальное перемещение, поворот и масштабирование базовой карты относительно графа трафика.
   - Точный пересчет смещения начала координат (`map_origin_offset_x`, `map_origin_offset_y` в мм, `map_origin_offset_theta` в градусах).
4. **Редактирование растровой карты SLAM**:
   - Инструменты **Paint Wall (Кисть)** и **Clear Area (Ластик)** с регулируемым размером кисти для очистки динамических препятствий и рисовки стен.
5. **Редактирование графа трафика и зон**:
   - **Узлы (Sites/Waypoints)**: Добавление, перемещение, удаление точек, редактирование имени, типа точки (стандартный узел, зарядная станция, точка разворота, точка погрузки/разгрузки) и порогов коллизий.
   - **Дуги/Сегменты (Lines/Edges)**: Соединение точек направленными линиями, настройка ограничения скорости (`speed`) и типа пути.
   - **Зоны (Zones)**: Рисование многоугольных зон (Keep-Out / Ограничение скорости / Погрузка) с настройкой параметров.

---

## 🛠 Технологический стек

- **Фреймворк**: Tauri (Rust + Webview) + Vite
- **Фронтенд**: React 18, TypeScript
- **Стилизация**: Tailwind CSS (Темная тема по умолчанию) + Lucide Icons
- **Рендеринг**: HTML5 High-Performance Canvas
- **Тестирование**: Vitest, Playwright

---

## 📦 Сборка и запуск

### Требования к окружению:
- Node.js (v18+)
- npm (v9+)
- Rust & Cargo (для сборки десктопного дистрибутива Tauri)

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск в режиме разработки (Web Preview)
```bash
npm run dev
```
Приложение будет доступно по адресу: `http://localhost:1420`

### 3. Запуск тестов и линтера
```bash
npm run test    # Запуск Vitest
npm run lint    # Проверка типов TypeScript
```

### 4. Сборка веб-дистрибутива
```bash
npm run build
```

### 5. Сборка десктопного приложения (Tauri Portable Executable)
```bash
npm run tauri build
```
Готовый исполняемый файл будет помещен в директорию `src-tauri/target/release/bundle/`.

## 📖 Инструкция по работе с приложением

### Инициализация и загрузка проекта
1. При запуске автоматически загружается пример проекта **Perekresto** из `.xrobot`.
2. В левой панели **"Map Workspace & Layers"** можно переключаться между предустановленными проектами (`Perekresto`, `1June Project`).
3. Для импорта собственных файлов используйте кнопку загрузки или перетащите `.json`, `.png` файлы.

### Инструменты верхней панели (Top Toolbar)
- ✋ **Pan Canvas**: Перемещение по холсту мышью.
- 🎯 **Select Element**: Выбор узла, линии или зоны на холсте для просмотра и редактирования их свойств в правой панели.
- ↔️ **Map Alignment**: Режим выравнивания карты. Позволяет вручную задать смещения `X (мм)`, `Y (мм)` и угол поворота `Theta (град)`.
- 📍 **Add Node/Site**: Клик по холсту добавляет новую путевую точку (Site).
- 🔗 **Add Edge/Path**: Последовательный клик по двум точкам создает направленный сегмент движения.
- ⏹ **Draw Polygon Zone**: Установка точек полигона. Нажмите кнопку "Complete Polygon" для завершения зоны.
- 🖌 **Paint Wall (Black)** / 🧼 **Clear Area (White)**: Рисование стен (черный) и очистка артефактов SLAM (белый) прямо по базовой карте.

### Управление слоями (Left Sidebar)
- Регуляторы прозрачности (Opacity) для базовой растровой карты и векторного графа трафика.
- Переключатели видимости (глаз) для каждого слоя.
- Кнопка **"Export Map & Traffic Files"**: Выгрузка обновленных файлов конфигурации (`map.json`, `project_info.json`, `perekresto_traffic.json` и `new_map.png`).

### Редактирование свойств (Right Sidebar)
При выборе любого элемента (точки, линии, зоны) в правой панели отображается карточка с его свойствами:
- Изменение имени, координат `X/Y (мм)`, типа точки и скорости линии.
- Удаление выбранного элемента с помощью иконки корзины 🗑.
